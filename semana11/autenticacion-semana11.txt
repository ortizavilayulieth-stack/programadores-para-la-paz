El login es el proceso mediante el cual un usuario ingresa a una aplicación usando sus credenciales, como un correo electrónico y una contraseña, para verificar su identidad. Algunas rutas deben estar protegidas para que solo los usuarios autorizados puedan acceder a información o funciones importantes. Esto ayuda a mantener la seguridad de la plataforma y evita accesos no permitidos. No debe exponerse públicamente información sensible como contraseñas, datos personales, documentos de identidad, direcciones, números de teléfono o información financiera, ya que podría ser utilizada de forma indebida
